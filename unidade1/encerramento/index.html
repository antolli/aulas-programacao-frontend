Exemplo 2: Destacar Item Selecionado

  • Sobre

Código da Função:

function destacarItem(elemento) {
// Remover destaque dos irmãos
const irmaos = elemento.parentNode.children;
for (let irmao of irmaos) {
irmao.classList.remove('ativo');
}
// Adicionar destaque ao elemento clicado
elemento.classList.add('ativo');
}
Como funciona: A função percorre todos os filhos do elemento pai (irmãos) e remove a classe 'ativo', depois adiciona apenas ao elemento clicado.
