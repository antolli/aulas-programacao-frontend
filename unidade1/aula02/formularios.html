Validação de Formulários

Validação HTML5 Nativa
O que é: Validação incorporada no HTML5 usando atributos como required, pattern, min/max, type, etc.
Características: Implementação direta sem JavaScript, porém com opções de personalização limitadas.
Preencha o formulário...
Código HTML5
<form id="html5Form">
    <input type="email" required placeholder="seu@email.com">
    <input type="tel" pattern="^\(\d{2}\)\s\d{4,5}-\d{4}$">
    <input type="number" min="18" max="100" required>
    <button type="submit">Validar</button>
</form>
Validação em Tempo Real
O que é: Validação que acontece enquanto o usuário digita, usando eventos como 'input' e 'blur'.
Características: Oferece feedback durante a digitação, requerendo mais código JavaScript.
Digite uma senha...
  • Mínimo 8 caracteres
  • Uma letra maiúscula
  • Uma letra minúscula
  • Um número
  • Um caractere especial
Digite nos campos acima...
Código JavaScript (Tempo Real)
document.getElementById('realtimeEmail').addEventListener('input', function() {
    const email = this.value;
    const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

    if (email.length === 0) {
        resetField(this);
    } else if (emailRegex.test(email)) {
        setValid(this, 'Email válido!');
    } else {
        setInvalid(this, 'Email inválido');
    }
});
