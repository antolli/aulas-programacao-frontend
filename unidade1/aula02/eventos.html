Eventos DOM - Exemplos Práticos

click - Evento de Clique
O que faz: Disparado quando o usuário clica em um elemento (mouse ou touch).
Aguardando clique...
Código JavaScript
document.getElementById('clickBtn').addEventListener('click', function() {
    const output = document.getElementById('clickOutput');
    const now = new Date().toLocaleTimeString();
    output.textContent = `Botão clicado às ${now}!`;
});
change - Evento de Mudança
O que faz: Disparado quando o valor de um input é alterado e o elemento perde o foco.
Nenhuma mudança detectada ainda...
Código JavaScript
// Para input de texto
document.getElementById('changeInput').addEventListener('change', function() {
    const output = document.getElementById('changeOutput');
    output.textContent = `Texto alterado para: "${this.value}"`;
});

// Para select
document.getElementById('changeSelect').addEventListener('change', function() {
    const output = document.getElementById('changeOutput');
    output.textContent = `Seleção alterada para: "${this.value}"`;
});
input - Evento de Entrada
O que faz: Disparado imediatamente sempre que o valor de um input é alterado (em tempo real).
Diferença do 'change': 'input' dispara a cada digitação, 'change' apenas quando perde o foco.
Digite algo no campo acima...
Código JavaScript
document.getElementById('inputField').addEventListener('input', function() {
    const output = document.getElementById('inputOutput');
    const length = this.value.length;
    output.textContent = `Digitando: "${this.value}" (${length} caracteres)`;
});
keydown - Tecla Pressionada
O que faz: Disparado quando uma tecla é pressionada (antes de ser liberada).
Pressione uma tecla...
Informações da tecla aparecerão aqui...
Código JavaScript
document.getElementById('keydownInput').addEventListener('keydown', function(event) {
    const keyDisplay = document.getElementById('keyDisplay');
    const output = document.getElementById('keydownOutput');
    
    keyDisplay.textContent = `Tecla: ${event.key}`;
    output.textContent = `Código: ${event.code} | Tecla: ${event.key} | Ctrl: ${event.ctrlKey} | Shift: ${event.shiftKey}`;
    
    // Exemplo: detectar Enter
    if (event.key === 'Enter') {
        output.textContent += ' - ENTER pressionado!';
    }
});
mouseover - Mouse Sobre Elemento
O que faz: Disparado quando o mouse entra na área de um elemento.
Passe o mouse sobre mim!
Mouse fora do elemento...
Código JavaScript
const mouseDiv = document.getElementById('mouseoverDiv');
const output = document.getElementById('mouseoverOutput');

mouseDiv.addEventListener('mouseover', function() {
    this.style.background = '#e83e8c';
    output.textContent = 'Mouse ENTROU no elemento!';
});

mouseDiv.addEventListener('mouseout', function() {
    this.style.background = '#17a2b8';
    output.textContent = 'Mouse SAIU do elemento!';
});
submit - Envio de Formulário
O que faz: Disparado quando um formulário é enviado (via botão submit ou Enter).
Preencha e envie o formulário...
Código JavaScript
document.getElementById('demoForm').addEventListener('submit', function(event) {
    event.preventDefault(); // Evita o envio real do formulário
    
    const name = document.getElementById('nameInput').value;
    const email = document.getElementById('emailInput').value;
    const output = document.getElementById('submitOutput');
    
    output.textContent = `Formulário enviado! Nome: ${name}, Email: ${email}`;
});
load - Carregamento Completo
O que faz: Disparado quando a página ou um elemento (como imagem) termina de carregar completamente.
Aguardando carregamento...
Código JavaScript
// Evento load da página
window.addEventListener('load', function() {
    console.log('Página completamente carregada!');
});

// Evento load de uma imagem
document.getElementById('loadImage').addEventListener('load', function() {
    const output = document.getElementById('loadOutput');
    output.textContent = 'Imagem carregada com sucesso!';
});
