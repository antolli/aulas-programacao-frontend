1. Transições Básicas

Transições fazem mudanças de propriedades CSS acontecerem gradualmente. Passe o mouse sobre os exemplos abaixo.

Hover Aqui

Mudança de Cor

Transição suave entre duas cores

.color-box {
    background: #3498db;
    transition: background-color 0.5s ease;
}

.color-box:hover {
    background-color: #e74c3c;
}
Aumentar

Escala (Scale)

Aumenta o tamanho do elemento

.scale-box {
    transition: transform 0.3s ease-in-out;
}

.scale-box:hover {
    transform: scale(1.2);
}
Mover →

Movimento (Translate)

Move o elemento horizontalmente

.move-box {
    transition: transform 0.3s ease;
}

.move-box:hover {
    transform: translateX(40px);
}
Girar

Rotação (Rotate)

Rotaciona o elemento

.rotate-box {
    transition: transform 0.3s ease;
}

.rotate-box:hover {
    transform: rotate(45deg);
}
Múltiplo

Múltiplas Propriedades

Várias transformações ao mesmo tempo

.multiple-box {
    transition: all 0.4s cubic-bezier(0.68, -0.55, 0.265, 1.55);
}

.multiple-box:hover {
    transform: rotate(10deg) scale(1.1);
    background: #c0392b;
    border-radius: 50%;
    box-shadow: 0 10px 30px rgba(0,0,0,0.3);
}
Opacidade

Transparência (Opacity)

Muda a opacidade do elemento

.opacity-box {
    opacity: 0.5;
    transition: opacity 0.3s ease;
}

.opacity-box:hover {
    opacity: 1;
}

2. Timing Functions

Diferentes curvas de aceleração para suas animações. Passe o mouse para ver como cada uma se comporta.

Linear
Ease
Ease-in
Ease-out
Ease-in-out
/* Velocidade constante */
transition-timing-function: linear;

/* Padrão - suave no início e fim */
transition-timing-function: ease;

/* Acelera no final */
transition-timing-function: ease-in;

/* Desacelera no final */
transition-timing-function: ease-out;

/* Acelera e desacelera */
transition-timing-function: ease-in-out;
Dica: Use "ease-out" para elementos que entram na tela e "ease-in" para elementos que saem.

3. Animações com Keyframes

Animações que se repetem automaticamente usando @keyframes. Estas rodam continuamente sem precisar de interação.

/* Definindo a animação */
@keyframes pulse {
    0%   { transform: scale(1); }
    50%  { transform: scale(1.05); }
    100% { transform: scale(1); }
}

/* Aplicando ao elemento */
.pulse-box {
    animation: pulse 2s infinite;

6. Acessibilidade

Respeite as preferências do usuário que prefere menos movimento. 

/* Animação padrão */
.animated-element {
    animation: bounce 1s infinite;
}

/* Desativa se o usuário prefere menos movimento */
@media (prefers-reduced-motion: reduce) {
    .animated-element {
        animation: none;
    }
    
    /* Ou reduza a intensidade */
    .card:hover {
        transform: scale(1.02); /* Menor que 1.05 */
    }
}
Como testar: No Chrome DevTools, pressione Ctrl+Shift+P e procure por "Emulate CSS prefers-reduced-motion".
